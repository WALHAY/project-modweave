\ssr{ВВЕДЕНИЕ}

Современная игровая индустрия активно развивается, и значительную роль в ее эволюции играют игровые модификации (моды). Моды позволяют пользователю изменять игровые механики, визуальные эффекты, сюжет и игровой процесс, расширяя возможности базовых игр. В связи с этим возникает потребность в специализированных платформах, которые обеспечивали бы удобное управление, хранение и распространение модификаций, а также поддерживали взаимодействие между авторами контента и конечными пользователями.

Цель работы --- разработка базы данных для платформы игровых модификаций, обеспечивающей хранение, управление и поиск модификаций, а также поддержку ролевой модели доступа на уровне БД.

Для достижения цели работы были поставлены следующие задачи:
\begin{itemize}
	\item провести анализ предметной области;
	\item спроектировать базу данных;
	\item разработать базу данных для хранения и обработки данных модификаций и связанных с ними сущностей;
	\item исследовать характеристики разработанной базы данных.
\end{itemize}
