# Контекст лабораторных ModWeave

Цель: выполнить WebLab №2 в `web/lab02`, затем №3 в ответвлённой `web/lab03`, с минимальным числом изменённых файлов. Лабораторные №4 и далее вне задания. Основание: `labs.pdf`, страницы 5–8; [сценарии и ADR](README.md#weblab-2--контракт-api), [контракт v2](docs/openapi.yaml).

Словарь: Game — игра; Mod — мод автора; Version — версия со статусом PENDING/APPROVED/REJECTED; File — объект версии в S3; Category — именованный справочник; Collection — упорядоченная подборка модов; Comment — отзыв к моду. Гость читает публичные данные, пользователь публикует, администратор управляет справочниками и модерацией.

Стек: Kotlin 2.3, Spring Boot 4 / Spring MVC 7, JDK 25, PostgreSQL 16, Redis, S3 (локально SeaweedFS). `layers/ui` содержит контроллеры и DTO, `layers/business-logic` — доменные модели, сервисы и интерфейсы Repository, `layers/data-access` — JPA-модели и реализации Repository. Корневой модуль собирает приложение и тесты. Не переносить работу с БД в контроллеры.

На этапе №2 менять только контракт, проверяющий скрипт и документацию. На этапе №3 сначала сопоставить контракт с контроллерами: общие операции сохранить, точечно добавить маршруты категорий, профиля, вставки в коллекцию и чтение комментариев. Не дублировать бизнес-логику v1. Swagger UI должен читать этот же YAML. Проверить HTTP-ответы через настоящий сервер и изолированные PostgreSQL/S3, включая намеренное нарушение контракта с последующим восстановлением.

Существующего TUI/GUI в этой ветке нет; технологический интерфейс — файлы `requests/*.http`. Не создавать новый TUI или GUI вместо отсутствующего. API v1 и эти HTTP-запросы должны продолжать работать.

Запуск и команды проверки приведены в [README](README.md#запуск). Без Docker: `./gradlew test --tests 'git.walhay.modweave.regression.*' ktfmtCheck`. Полный прогон: `./gradlew test ktfmtCheck`. Контракт: `build/openapi-venv/bin/python docs/check_openapi.py` и команды Redocly/Prism из README. Тесты используют отдельные контейнеры, не локальную рабочую БД. `.env` и реальные токены в документацию и задания не включать.

Подтверждённые ограничения: локальные даты без часового пояса, поиск модов по названию, постраничный просмотр для выбора по gameId/категории, модерация по отдельному моду. Перестройка этих функций, нагрузочные эксперименты, reverse proxy и SPA не входят в текущую задачу.
